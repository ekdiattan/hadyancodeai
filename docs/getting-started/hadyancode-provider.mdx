HadyanCode (usage-billing) is the simplest way to get started with pay-as-you-go model access in HadyanCode.

Instead of managing separate API keys across multiple vendors, you sign in once, add **HadyanCode credits**, and select from available models directly in HadyanCode.

If you want a flat monthly subscription that offers 2-5x the usage on selected open coding models compared to standard API rate, use [HadyanCodePass](/getting-started/hadyancodepass) instead. HadyanCodePass is a separate provider in HadyanCode.

## Why use HadyanCode (usage-billing)

- **Fastest setup**: no manual API key copy/paste; access to 100+ models supported by HadyanCode
- **One account**: sign in once with Google, GitHub, or email
- **Pay as you go**: add HadyanCode credits and use one balance across supported models
- **Free options**: look for models tagged **FREE** in the selector

## How it works

HadyanCode (usage-billing) is the pay-as-you-go provider in HadyanCode. Add HadyanCode credits, then select **HadyanCode** wherever you configure your provider.

- **IDE Extension**: Go to IDE extension settings, set **API Provider** to **HadyanCode**, and sign in.
- **CLI**: Go to `/settings` and select **HadyanCode** as your provider.

## Credits and usage

- Add **HadyanCode credits** from your [HadyanCode dashboard](https://app.cline.bot/dashboard)
- Credits are used on a pay-as-you-go basis when you select paid models through HadyanCode (usage-billing)
- View usage in HadyanCode Settings → **View Usage**
- Switch organizations in HadyanCode Settings → **Switch Organization**

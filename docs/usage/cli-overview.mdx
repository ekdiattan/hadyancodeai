## Prerequisites

- HadyanCode CLI installed (install via `npm i -g hadyancode`)
- Provider authenticated (`hadyancode auth`) — use the HadyanCode Provider, HadyanCodePass, or your own provider key ([Authorization Guide](/getting-started/authorizing-with-hadyancode#cli-setup))

## Quick Start

```bash
# Interactive session
hadyancode

# Run one task immediately
hadyancode "refactor this module to use async/await"

# Structured output for scripts
hadyancode --json "list TODO comments"
```

## Headless mode

Use headless mode for scripts/automation and processable output.

Headless is triggered when using flags like `--json`, when stdin is piped, or when output is redirected.

#### When headless activates

| Invocation | Reason |
|---|---|
| `hadyancode --json "task"` | JSON output mode |
| `cat file \| hadyancode "task"` | stdin is piped |
| `hadyancode "task" > output.txt` | stdout is redirected |

```bash
# CI/script style execution
git diff | hadyancode "review these changes"

# JSON for parsing
hadyancode --json "summarize this changelog" | jq -r '.text'
```

See: [Headless Mode](#headless-mode)

### Autonomous execution

For fully unattended runs, use auto-approval:

```bash
hadyancode --auto-approve true "run tests and fix failures"
```

Mode selection also works in headless runs:

```bash
# plan-first
hadyancode -p "design migration plan"

# act immediately (default)
hadyancode "apply migration"
```

<Warning>
Autonomous execution can modify files and run commands without further prompts. Use a clean branch and review results.
</Warning>

## High-Value Commands

```bash
hadyancode --help
hadyancode <command> --help
```

| Command | Purpose |
|---|---|
| `hadyancode` | Start interactive mode or run a prompt |
| `hadyancode auth` | Authenticate and set provider/model |
| `hadyancode config` | Open the interactive config view |
| `hadyancode mcp` | Manage MCP servers |
| `hadyancode doctor` | Diagnose/fix configuration issues |
| `hadyancode history` | Show and manage task history |
| `hadyancode schedule` | Manage scheduled tasks |
| `hadyancode hub` | Manage local hub daemon |
| `hadyancode kanban` | Launch Kanban app |

## Most-Used Global Flags

Source of truth: [CLI Reference](/cli/cli-reference)

| Flag | Purpose |
|---|---|
| `-p, --plan` | Start in Plan mode |
| `--auto-approve <boolean>` | Global tool auto-approval (`true`/`false`, default `true`) |
| `-m, --model <model>` | Override model for this run |
| `-P, --provider <id>` | Override provider for this run |
| `-c, --cwd <path>` | Set working directory |
| `--config <dir>` | Use config directory |
| `--data-dir <dir>` | Use isolated local state |
| `--json` | Output newline-delimited JSON messages |
| `--thinking <level>` | Set reasoning effort: `none\|low\|medium\|high\|xhigh` (default `medium`) |
| `-t, --timeout <seconds>` | Set task timeout |

## Automation Patterns

### Pipe context in

```bash
cat README.md | hadyancode "summarize key setup steps"
git diff | hadyancode "review for potential regressions"
```

### Chain tasks

```bash
git diff | hadyancode "explain these changes" | hadyancode "write a commit message"
```

### Restrict command execution

```bash
export HADYANCODE_COMMAND_PERMISSIONS='{"allow": ["npm *", "git *"], "deny": ["rm -rf *", "sudo *"]}'
```

### Include images in tasks

```bash
hadyancode -i "fix the layout issue shown in @./screenshot.png"

# or reference inline
hadyancode "fix the UI shown in @./design-mockup.png"
```

### Set execution timeout

```bash
hadyancode --timeout 600 "run full test suite"
```

## JSON Output Schema

When using `--json`, each line is a JSON message object.

```json
{"type":"say","text":"I'll create the file now.","ts":1760501486669,"say":"text"}
```

| Field | Type | Description |
|---|---|---|
| `type` | `"ask"` or `"say"` | Message category |
| `text` | `string` | Message content |
| `ts` | `number` | Unix timestamp in milliseconds |
| `say` | `string` | Subtype when `type` is `"say"` |
| `ask` | `string` | Subtype when `type` is `"ask"` |
| `reasoning` | `string` | Optional model reasoning |
| `partial` | `boolean` | Streaming flag |
